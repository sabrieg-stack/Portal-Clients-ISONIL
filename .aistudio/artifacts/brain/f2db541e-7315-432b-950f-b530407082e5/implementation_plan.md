# بوابة العملاء - Portal Clients ISONIL (Isonil Maroc)

بوابة رقمية تفاعلية متكاملة لعملاء وإدارة شركة **ISONIL Maroc** المتخصصة في العزل الحراري الصناعي (*Isolation Thermique Industrielle*)، توفر بيئة عمل مشتركة وأرشيفاً رقمياً محكماً للمشاريع والمرفقات (صور، فيديو، وثائق، تقارير، ملاحظات) بنظام شبيه بالبريد الإلكتروني المتطور مع دعم كامل ومستقل للغتين العربية والفرنسية وأعلى معايير الخصوصية والأمان.

## 1. نظرة عامة والمفهوم الجوهري

### 1.1 ما تقدمه البوابة
- **مساحة عمل وأرشيف رقمي مستدام**: قناة اتصال رسمية وتوثيقية بين العميل وإدارة ISONIL أثناء تنفيذ مشاريع العزل الحراري وما بعدها، لمنع فقدان البيانات والتقارير الفنية.
- **نظام ثنائي اللغة بنسبة 100%**: إمكانية التبديل بنقرة واحدة بين العربية الفصحى (واجهة كاملة RTL) والفرنسية المهنية (واجهة كاملة LTR)، مع تعريب وفرنجة كافة المصطلحات الفنية وأسماء الحقول بدون دمج أو كلمات هجينة.
- **جدار عزل الخصوصية (Zero Data Leakage)**: كل عميل يرى فقط مشاريعه ومرفقاته المعتمدة، مع عزل كامل لمعلومات العملاء الآخرين وبيانات الإدارة الحساسة.
- **إدارة المرفقات بلا حدود**: محاكاة رفع وتنزيل حقيقي مع أشرطة تقدم حية، دعم كافة الامتدادات (صور عزل، فيديوهات ميدانية، دفاتر تحملات PDF، تقارير حرارية، ملاحظات).

## 3. القرارات المعمارية وبنية البيانات

### 3.1 فصل الأدوار والصلاحيات
1. **العميل (Client)**:
   - الاطلاع على مشاريعه المسندة إليه فقط.
   - تصفح المرفقات الواردة من إدارة ISONIL (تقارير تقدم الأشغال، شهادات الجودة، صور العزل الحراري، الفواتير).
   - إرسال مرفقات صادرة للإدارة (ملاحظات ميدانية، استفسارات، مستندات طلب تعديل).
   - لا يمكنه رؤية أي مستند يخص عميلاً آخر.
2. **الإدارة (Admin)**:
   - استعراض شامل لكافة المشاريع والعملاء.
   - مراجعة وتفعيل أو رفض طلبات فتح الحساب الجديدة.
   - مراقبة سعة التخزين المستهلكة الإجمالية ولكل مشروع.
   - إضافة مشاريع وربطها بالعملاء، ورفع مرفقات مشتركة أو تقارير رسمية.

## 4. خطة التنفيذ المنهجية

1. **التهيئة واللغات ومحرك الحالة**:
   - إعداد قاموس اللغات الشامل (العربية الكاملة والفرنسية الكاملة).
   - محرك إدارة الحالة المحلية مع قابلية التكامل التام مع Firebase (Firestore + Storage).
2. **شاشة الاستقبال السينمائية**:
   - مشهد بانورامي بأسلوب سينمائي يبرز صورة ISONIL مع مؤشر تقدم 3.5 ثوانٍ وإمكانية التخطي الفوري.
3. **نظام المصادقة والتسجيل المحمي**:
   - تبديل سلس بين دخول العميل، دخول الإدارة، طلب حساب جديد، واستعادة كلمة المرور مع إشعار بالرابط المرسل.
4. **فضاء العميل (Mailbox-Style Portal)**:
   - قائمة المشاريع والفلتر العلوي حسب النوع والتصنيف.
   - قائمة المرفقات الشبيهة بالبريد (صندوق الوارد والصادر) مع مؤشرات التاريخ والحجم.
   - نافذة معاينة المرفق الغنية: عرض الصور/الفيديو/المستندات مع أزرار الطباعة، التنزيل (بمؤشر تقدم)، المشاركة، وإعادة التوجيه.
   - أداة رفع مرفقات متعددة بسلاسة وبلا تعليق.
5. **لوحة تحكم الإدارة (Admin Command Center)**:
   - إحصائيات سعة التخزين، عدد المشاريع النشطة، وحالة العملاء.
   - قائمة طلبات الحسابات المعلقة مع إمكانية التفعيل أو الرفض بنقرة واحدة.
   - إنشاء مشاريع ورفع مرفقات للعملاء.
6. **الهيدر والفوتر والتفاعل الفوري**:
   - تضمين شعار ISONIL المرفق بدون نص مكرر.
   - ربط أزرار الهاتف، الواتساب، البريد، والخريطة لتعمل فورياً.
   - أزرار تسجيل الخروج والعودة للخلف في كل مرحلة.
